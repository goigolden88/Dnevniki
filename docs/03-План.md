## Логика порядка

Циклы идут первыми: они дают пользу с первого дня, не требуя накопления истории — вводишь последние известные даты и сразу получаешь экран просроченного.

Синхронизация идёт раньше остальных модулей, хотя выглядит скучнее. Причина: она затрагивает каждую сущность, и прикручивать её к трём готовым модулям дороже, чем к одному.

Здоровье и контент раскрываются только со временем — первому нужен год данных, второму конец года. Поэтому они позже, но заводить их надо не откладывая, чтобы данные начали копиться.

---

## Этап 1 — Циклы, локально

- Экран «Сейчас»: позиции по срочности, полоса интервала, статусы
- Отметка в один тап с мгновенным откликом
- История позиции, разброс интервалов, медиана
- Управление позициями и категориями
- Шаблоны быстрого ввода
- Загрузка стартовых данных из подготовленного JSON
- Экспорт JSON

**Готово когда:** реальные данные из Obsidian живут в приложении, Obsidian для этих дневников больше не нужен.

## Этап 2 — Синхронизация

- Приватный репозиторий данных. Числился в Этапе 0, но заводить его раньше, чем появится кому в него писать, незачем
- Экран настроек: репозиторий, токен, проверка доступа
- `core/github.ts` — чтение и запись файлов с версиями
- `core/sync.ts` — очередь, слияние по `updatedAt`, повтор при конфликте
- Индикатор состояния: синхронизировано / ждёт / ошибка
- Ручной экспорт и импорт файлом
- Режим без синхронизации по умолчанию для посторонних

**Готово когда:** отметка на телефоне появляется на компе, и наоборот. Обрыв сети ничего не ломает.

## Этап 3 — Здоровье

- Эпизоды: создание, закрытие, открытые эпизоды на главной
- Теги симптомов
- Измерения и график веса
- Тренировки
- Аналитика: частота, длительность, сезонность, повторяющиеся симптомы
- Сводка для врача на печать

**Готово когда:** можно распечатать хронологию болезней за период одной страницей.

## Этап 4 — Контент

- Записи, статусы, оценки, комментарии
- Список «к просмотру»: статус `planned`, дата начала не задана (Р-21)
- «Сейчас смотрю» на главной
- Итоги года: распределение оценок, разбивка по типам, начато против закончено
- Необязательная подтяжка обложек и метаданных из внешних баз

**Готово когда:** заполнены данные 2026 года и итоги года смотрятся осмысленно.

## Этап 5 — Доводка

- Главный экран «Сегодня», собирающий все три модуля
- Единая лента и поиск
- Экспорт в markdown
- Веб-пуши для просроченного

## Отложено

- Дневник Депры — другой тип данных, решение о включении не принято
- Интеграция с приложениями по еде и тайм-менеджменту
- Использование поля `refs` для связей между модулями
- Расшифровка и классификация дневника «Исходров»
