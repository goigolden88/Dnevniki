# Дневники

Персональное PWA вместо набора дневников в Obsidian: циклическое обслуживание, здоровье, потребление контента.

**https://goigolden88.github.io/Dnevniki/**

Открывается в браузере, ставится иконкой на телефон, работает без сети. Данные лежат в браузере, наружу без настройки не уходят.

## Команды

```
npm install
npm run dev       # разработка, service worker включён
npm run build     # проверка типов и сборка в dist/
npm run preview   # посмотреть собранное
npm run test      # тесты расчёта
npm run smoke     # прогон собранного приложения в браузере
npm run icons     # перерисовать иконки PWA из public/favicon.svg

npm run check:data -- <копия>   # миграции и расчёт на копии настоящих данных
npm run smoke -- --data <копия> # все экраны на копии настоящих данных
```

`npm run smoke` собирает приложение, открывает его в headless-браузере и проходит обычный путь человека через все три модуля, ленту и настройки. Отвечает на один вопрос — открывается ли приложение и не падает ли на обычном пути. Тестов экранов в проекте нет и не будет, это замена им (Р-41). Нужен любой браузер на Chromium; свой путь задаётся переменной `CHROME_PATH`.

`npm run icons` запускается руками и только при смене иконки. В сборку не входит.

## Деплой

Пуш в `main` → GitHub Actions собирает и публикует на Pages. Ручных шагов нет.

Однократная настройка, если репозиторий разворачивается заново: **Settings → Pages → Source → GitHub Actions**. Без неё workflow отработает и упадёт на последнем шаге с «Not Found».

## Подводные камни

**`base` в `vite.config.ts` равен имени репозитория** — `/Dnevniki/`. Pages отдаёт сайт проекта не с корня домена. При неверном `base` сборка проходит зелёной, а страница открывается белой, и все скрипты уходят в 404. Переименуете репозиторий — правьте эту строку.

**Service worker обновляется сам.** `registerType: 'autoUpdate'`: новая сборка забирает управление немедленно и перезагружает страницу. Проверить, что обновление доехало до телефона, можно по дате сборки на экране «Настройки».

**Секретов в этом репозитории нет и не будет** — он публичный. Токен доступа к репозиторию данных — поле в настройках приложения, хранится только в браузере.
